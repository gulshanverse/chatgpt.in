# chatgpt.in

A high-fidelity ChatGPT-inspired UI clone built for a hackathon, based on the provided current UI reference screenshots.

## Status

Phase 1 foundation is implemented on `feat/chatgpt-ui-clone-foundation`:

- Responsive dark application shell
- Sidebar, chats, projects, account footer
- Account menu + Help submenu
- Conversation overflow menu
- Chat composer with attachment chips
- Settings modal with navigation and General/Personalization surfaces
- Profile modal
- Upgrade-plan screen
- Responsive layout foundations

## Next phases

1. Run/build validation and fix frontend issues
2. Pixel-level visual refinement against reference screenshots
3. Complete interaction/state coverage
4. Chat streaming and persistence
5. Authentication and production hardening
6. Screenshot-based visual QA at reference viewport sizes

This is an independent implementation for a hackathon and is not affiliated with or endorsed by OpenAI.
